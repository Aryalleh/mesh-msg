    You

    What other nodes see. Leave the name empty for privacy.

    Relays

    Servers that hold encrypted messages until the other side picks them up. "Via" is how to reach them: direct, tor, or a proxy such as socks5://127.0.0.1:1080 (a VPN or Psiphon client).

    Share my internet with the mesh (gateway)

    Phones and nodes near you with no internet (Bluetooth, LAN, LoRa) send and get their messages through this computer.

    Bridges

    Copy messages between two relays that can't reach each other (for example a domestic and a foreign relay). Both must be in the relay list.

    Local network

    Mesh with other meshd computers on the same Wi-Fi / LAN, no internet needed.

    LoRa node (USB)

    A Heltec V3, T-Beam S3, RAK4631 or T-Echo with mesh-msg firmware, plugged in by USB. This computer carries its traffic.

    Account

    Your account is a secret key on this computer. Back it up, or you lose the account with the disk. The backup is locked with a passphrase.

    Changes apply when you save; links reconnect for a moment.

    Add contact

    My contact link

    Share this with people so they can message you. It contains only public keys.

    Back up account

    Pick a passphrase (8+ characters). You need it to restore; nobody can recover it.

    Keep this somewhere safe (password manager, paper). Anyone with it and the passphrase can use your account.

    Restore from backup

    This replaces the account on this computer. The current key is kept next to it as identity.key.replaced-…; back it up first if you still need it.
