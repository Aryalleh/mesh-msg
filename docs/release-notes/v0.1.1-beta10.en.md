Fixed default device password for the Mava board.

- Every Mava board now starts with the device password 12345678 (hotspot Mava-XXXX and setup panel) instead of a random one. Set your own in the setup panel: it is kept from then on. A full erase or "Install everything" brings back 12345678.
- Change it once the board is set up: anyone nearby who knows the default can open the panel while the hotspot is on.
- Boards that already have a password keep it after "Update firmware only"; use "Install everything" to go back to 12345678.
- Includes everything from 0.1.1-beta9 (hotspot without the switch, Wi-Fi over USB). Still not tested on real hardware.
