Fixes for the update check.

- "Check for updates" no longer says "Could not send": it shows the real result ("Mava … is up to date", "Mava … is available" or why the check failed).
- New releases are found much sooner: the app asks GitHub as well as the relay and takes the newer answer (where GitHub is blocked, the relay's answer is used), checks about every 6 hours instead of once a day, and checks again when you open the app if the last check was over an hour ago. Relays refresh their release info every 10 minutes instead of every hour.
- Everything from 0.1.1-beta3: profile pictures over direct connections, chat folders, Telegram-like desktop theme, quiet "Mava is running" notification.
