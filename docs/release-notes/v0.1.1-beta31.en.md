Board: the display moves to one side of the ESP32-S3 DevKitC.

- The whole display (ILI9341 screen, XPT2046 touch, microSD) is now wired to the DevKitC's left header, in the display header's order: CS 15, RESET 16, DC 17, SDI (MOSI) 18, SCK 3, LED 46, SDO (MISO) 9; touch T_CLK 3, T_CS 5, T_DIN 18, T_DO 9, T_IRQ 6; SD card CS 7. VCC to 3V3 with the module's J1 bridged.
- Audio pins (not used yet) and the keyboard-module interrupt moved to the right header (I2S 39/40/41/42/45, keyboard INT 21). LoRa pins are unchanged.
- Rewire the display before flashing: with this firmware the old display pins (21, 2, 42, 39, 40, 41, 45) are no longer the screen.
- Update the board with Mava Flasher ("Update firmware only" keeps the account). Not yet tested on real hardware.
