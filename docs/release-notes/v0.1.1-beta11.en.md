Mava Screen: the handheld's screen on your phone.

- New app: mava-screen-…-android.apk shows the handheld's screen on an Android phone over a USB-OTG cable, live. Touch the picture to tap, use the buttons for the handheld's keys (call, menu, arrows, OK, back, end), and type with the phone's keyboard in any language.
- A Mava board without a screen fitted runs the same interface, so the phone becomes its screen.
- Only what changes on the screen is sent, so it stays quick over USB.
- Plug the board's own USB socket into the phone. Only one app can use that USB port at a time: close the flasher or Mava's LoRa over USB first.
- Fixed: the browser app on the board stopped with "WebAssembly.instantiate(): expected magic word 00 61 73 6d, found 1f 8b". The board sent its compressed WebAssembly file without saying it was compressed; it now does, and the page also unpacks it itself.
- Update the board with Mava Flasher ("Update firmware only") to use it. Still not tested on real hardware.
