برد: نمایشگر به یک طرف ESP32-S3 DevKitC منتقل شد.

- کل نمایشگر (صفحهٔ ILI9341، لمسی XPT2046، کارت microSD) حالا به ردیف پین‌های سمت چپ DevKitC وصل می‌شود، به ترتیب پین‌های خود نمایشگر: CS ← ۱۵، RESET ← ۱۶، DC ← ۱۷، SDI (MOSI) ← ۱۸، SCK ← ۳، LED ← ۴۶، SDO (MISO) ← ۹؛ لمسی: T_CLK ← ۳، T_CS ← ۵، T_DIN ← ۱۸، T_DO ← ۹، T_IRQ ← ۶؛ کارت SD: CS ← ۷. VCC به 3V3 و جامپر J1 ماژول وصل (لحیم) شود.
- پین‌های صدا (هنوز استفاده نمی‌شوند) و وقفهٔ ماژول کیبورد به ردیف سمت راست رفتند (I2S روی ۳۹/۴۰/۴۱/۴۲/۴۵، وقفهٔ کیبورد ۲۱). پین‌های LoRa تغییری نکرده‌اند.
- قبل از فلش، نمایشگر را دوباره سیم‌کشی کنید: با این فرم‌ور پین‌های قبلی نمایشگر (۲۱، ۲، ۴۲، ۳۹، ۴۰، ۴۱، ۴۵) دیگر به صفحه مربوط نیستند.
- برد را با فلشر Mava به‌روز کنید («فقط به‌روزرسانی فرم‌ور» حساب را نگه می‌دارد). هنوز روی سخت‌افزار واقعی آزموده نشده است.
