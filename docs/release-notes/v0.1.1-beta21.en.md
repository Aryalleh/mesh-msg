Fix: "404 not found" on the board's web page.

- Wiping the board (new identity) erased its whole storage, including the browser app the board serves to phones and iPhones. After that, the board's web page answered "404 not found". A wipe now keeps the browser app.
- If the browser app is missing from a board, its web page now says so and how to fix it, instead of a bare 404. Other unknown addresses lead to the app. The board log's first line says whether the browser app is installed.
- To fix a board that shows 404 now: flash it once with Mava Flasher and choose "Install everything" (this also gives the board a new identity and the default device password 12345678). After that, "Update firmware only" is enough.
- Still not tested on real hardware.
