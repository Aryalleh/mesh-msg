Flasher downloads the newest firmware itself; relays update themselves; the board log shows where messages stop.

- Mava Flasher (Android): it now checks GitHub for the newest firmware when it starts (and with "Check GitHub for newer firmware"). It downloads the board images and flashes them, so a new firmware no longer needs a new flasher APK. Only a release signed with the project's key is accepted, and the download must match its SHA-256. The firmware built into the APK stays as the offline fallback. Install this flasher once; later firmware comes by itself.
- Relays: the installer turns on automatic updates. Every 6 hours a timer runs `meshmsg-relay -self-update`, which installs a newer signed release from GitHub and restarts the relay. Config and data are kept. A relay installed earlier gets this by running the installer once more (`curl -fsSL https://raw.githubusercontent.com/Aryalleh/mesh-msg/main/server/deploy/install.sh | sudo sh`).
- Board log: the 10-second status is now four lines (it was cut off before): Wi-Fi and radio; the relay (with the reason it fails); the account ("messages for it N (opened, unreadable), sent, delivered, contacts"); Bluetooth ("packets in N, out M"). This shows where a message stops: on Bluetooth, at the board, or in decryption.
- Still not tested on real hardware.
