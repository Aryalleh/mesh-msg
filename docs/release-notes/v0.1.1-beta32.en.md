Mava Screen: keys and keyboard only, and the phone as the handheld's speaker and microphone. Pre-release simulators gathered in one place, to leave with v1.

- Mava Screen, "Show the board's screen here": switch it off when the board has its own display. The phone stops receiving the picture and stays the handheld's keys and keyboard.
- Mava Screen, "Board sound on this phone's speaker" and "This phone's microphone to the board": the phone stands in for the audio hardware over USB (8 kHz, 20 ms frames). The board now has sounds: a chime when a message arrives, a click on each key, and Settings → Sound test. Settings shows the microphone level and has an Echo test (microphone back to the speaker; use headphones).
- Everything the phone simulates (screen, keys, audio) is now one firmware library, built only into pre-releases. Version 1 builds leave it out, and Mava Screen is published only with pre-releases. The board's own sounds stay.
- Update the board with Mava Flasher ("Update firmware only" keeps the account) and install the new Mava Screen. Not yet tested on real hardware.
