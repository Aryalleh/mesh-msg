The Mava board opens its setup hotspot by itself, and takes Wi-Fi settings over USB.

- A board with no Wi-Fi saved (a new board, or one without the setup switch fitted) now opens its hotspot Mava-XXXX by itself. Join it with the device password and the setup panel opens. Before, it turned Wi-Fi off and waited for the switch.
- Wi-Fi over the cable: the Android flasher's new "Board Wi-Fi" section, or `mesh lora wifi ssid=… password=…` on a PC, saves the network on the board over USB. "Open hotspot now" / `mesh lora hotspot on` opens the setup hotspot without the switch.
- After saving Wi-Fi in the panel with the switch off, the board leaves the hotspot and joins the network by itself.
- The board's log repeats the hotspot name, device password and BLE passkey every 10 seconds, and names each step while it starts (`boot: Wi-Fi`, `boot: radio`, …), so a step that hangs on a board without some part is easy to see. Wi-Fi now starts before the radio, screen and keyboard.
- Install it with the Android flasher ("Update firmware only" keeps identity and settings) or `./mava-flash firmware`. Still not tested on real hardware.
