Fixes: the phone's Bluetooth mesh, and messages to the board's account.

- Android: once a Mava board had been connected with "Connect board over Bluetooth", the phone's own Bluetooth mesh stopped working (both used the same internal name), and the Network screen asked to allow Bluetooth again although it was allowed. Fixed: both work side by side. If Bluetooth is really off, the card now says so and opens Bluetooth settings.
- Board: messages sent to the board's account through the relay never arrived when the board had no clock (NTP blocked): the account could not announce itself, so the board never asked the relay for its messages. Now the board always fetches its own account's messages, and takes the time from the relay when NTP doesn't answer, so the account announces itself too.
- The board log shows the account's state ("account on, announced as …" or "waiting for the clock").
- Update both: the Android app, and the board with Mava Flasher ("Update firmware only"). Still not tested on real hardware.
