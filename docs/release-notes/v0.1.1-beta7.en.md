Test release: the Mava board, its Linux flasher, browser access for iPhones, new look.

- Mava board (ESP32-S3 + SX1262): one device that carries messages over LoRa on the Meshtastic network, Bluetooth, USB and Wi-Fi to a relay, all at once. A physical switch opens a setup hotspot with its own panel. This is a test build: it has not run on real hardware yet.
- Board flasher for Linux: download mava-board-flasher-…-linux.tar.gz, run ./mava-flash board --erase the first time (new identity and device password), then ./mava-flash board. It also flashes the keyboard module (Raspberry Pi Pico) of the handheld.
- iPhones and any browser: on the same Wi-Fi as a board, open the address shown on the handheld (or http://<board>/app/) and chat from the browser. Text only for now; calls in the browser come later.
- Handheld: screen UI in Persian and English with a touch keyboard, three keyboard options (own keypad, BlackBerry 9900 keyboard, with or without its trackpad).
- New violet design on the handheld, the web client and the board's setup panel.
- LoRa packets are now at most 233 bytes (the Meshtastic limit): update phones, desktops and boards together to use LoRa.
- Apps keep the official relay list and pass it to nearby devices, so a phone that never reached GitHub still gets new relays.
