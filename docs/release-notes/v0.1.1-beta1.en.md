First beta of Mava.

- New: the app and meshd check for new releases by themselves. You will see a banner (and on Android one notification) when a newer version is out. Updates are signed; Android verifies the download before installing, desktop updates with `mesh update`.
- Settings → About shows the version and has "Check for updates".
- Relays answer update checks too (`GET /v1/release`), so updates are found where GitHub is blocked.
- Everything from 0.1.0-alpha13: direct links across NAT, 1:1 voice calls on Android, normal and important media.

Not yet tested on real phones: Bluetooth mesh and USB LoRa. Report problems at https://github.com/Aryalleh/mesh-msg/issues
