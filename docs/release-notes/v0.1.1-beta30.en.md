Fix: the board refused every message. Fix: Bluetooth link between phone and board dropping ("status 17").

- The board's message store (256 slots) had filled up with delivery receipts, which ranked above messages, so every new message was refused and never reached the board's messenger (log: "receipts 256 … refused"). Receipts now keep their top rank only up to a quarter of the store; beyond that, messages push them out. At boot the board drops old receipts beyond that quarter (the log says how many).
- Bluetooth: when the board sent its store to a phone, its Bluetooth buffers filled up and it refused the phone's next write ("status 17"). The phone then dropped the link and reconnected, and the board sent everything again. The board now keeps buffers free for the phone's writes, and the phone retries a refused write instead of dropping the link.
- Android, Network screen: "Last disconnect" now keeps the first reason. Data arriving after a disconnect no longer replaces it with "chunk from unknown peer".
- Board log: the Bluetooth line shows its buffers ("buffers 14/20 free").
- Update the board with Mava Flasher ("Update firmware only" keeps the account) and the Android app. Not yet tested on real hardware.
